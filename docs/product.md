# 导入式文件管理系统 — 产品需求分析

> 定位：**导入式**文件管理。文件先通过导入接口复制进内部数据库，再进行查看、管理、打标签。
> 主界面以移动端为标准（参考 Google Files / 小米文件管理器）。UI 采用液态玻璃（Glassmorphism）风格。

## 一、产品价值
用户把系统文件导入后，在一个安全、统一、可标签化管理的数据空间里查看/管理，
不依赖系统文件管理器，跨平台一致（尤其 iOS 无法直接访问系统文件）。

## 二、核心流程
```
导入(系统/相册/分享) → 内部数据库(files) → 查看/预览 → 管理(移动/重命名/删除/标签) → 导出/分享
```

## 三、功能模块（产品视角）

### 1. 首页 / 文件库（Library）
- 顶部：**液态玻璃搜索栏** + 标题
- **分类入口**（非标签，是类型）：图片 / 视频 / 音频 / 文档 / 压缩包 / 最近
- 文件网格（卡片式）：图片/视频显示预览图、名称、大小
- 底部导航（移动端标准）：文件库 / 标签 / 更多

### 2. 导入 / 导出（强制项）
- **导入**：系统文件多选、文件夹递归、相册（移动端）
- **导出**：把内部文件复制回系统用户选定位置 / 分享

### 3. 文件操作
- 预览（按类型打开查看器）
- 重命名 / 删除 / 移动到文件夹 / 复制
- 多选批量操作（移动 / 删除 / 打标签 / 导出）
- 收藏（星标）

### 4. 标签系统（按设计重构，强制项）
- 标签 = **用户自定义名 + 颜色**，与文件类型无关
- 单个 / 批量给文件打标签
- 标签页：列出所有标签 + 文件计数，点标签查看该标签文件
- 标签管理：新建 / 重命名 / 改色 / 删除
- 搜索支持按标签过滤

### 5. 搜索
- 按名称、按标签、按类型

### 6. 存储 / 统计
- 已导入文件数、总大小、按类型占比

## 四、强制项落地要点
1. **液态玻璃（Glassmorphism）**：用 Flutter `BackdropFilter` + `ImageFilter.blur` 实现半透明模糊卡片、app bar、底部导航，背景用渐变/色彩，卡片带半透明白 + 圆角 + 细边框。
2. **移动端布局**：底部导航 + 搜索栏 + 网格卡片 + 操作 FAB，参照 Google Files / 小米文件管理器。
3. **导入/导出**：导入用 file_selector；导出用 `getSaveLocation` + 原生 `db_export_file`。
4. **UI 协调**：统一定义间距/字号 token，卡片内文字与区域比例协调，避免大片空白 + 小字。
5. **标签重构**：独立标签页 + 颜色 + 计数 + 批量打标，融入"分类(类型)"与"标签(用户)"分开。

## 五、优先级（MVP 顺序）
1. 移动端首页改造（玻璃 UI + 底部导航 + 分类）
2. 导入/导出
3. 标签页重构（颜色/计数/批量）
4. 搜索/统计/收藏
