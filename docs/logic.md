# 导入式文件管理系统 — 逻辑文档（实现规范）

> 本文档是本系统的**唯一实现规范**，所有功能严格按此实现。若与代码冲突，以本文档为准。

## 0. 命名
- **主界面不叫「文件库」，叫「文件」**。
- 底部导航：`文件` / `标签` / `更多`。
- 首页标题显示当前目录路径（面包屑）。

## 1. 数据模型（数据库 files/tags/file_tags）
- **files**：id, name, ext(类型), mime, size, internal_path(内部副本路径), source_path(导入来源),
  source_type, is_dir, parent_id(库内目录树), import_time, deleted。
- **tags**：id, name, color。**标签 = 用户自定义名 + 颜色，与文件类型无关**。
- **file_tags**：file_id, tag_id（多对多）。
- **类型（ext/分类）是独立概念**：仅用于统计/图标，**不作为标签**，不在文件列表展示。

## 2. 首页「文件」= 目录结构
- 显示库内目录树（根目录开始），面包屑路径 + 当前目录内容列表。
- 点击目录进入；面包屑可跳转任意层级。
- 顶部工具栏（AppBar）：
  - 标题：当前路径。
  - 动作：搜索 / 排序(名称/大小/导入时间) / 视图(列表/网格)。
  - **右上角「+」菜单**：导入文件 / 导入文件夹 / 新建目录。
- **不使用 FAB**；**首页不显示标签栏、不显示类型分类栏**。

## 3. 列表视图（ListView）
- 每个文件/文件夹行**高度统一固定**（如 64dp），图片/视频左侧显示预览图/封面，右侧名称+大小。
- 名称超长省略号，不换行。

## 4. 网格视图（GridView）
- **列数可配置**（设置在设置页修改，存储用户偏好）。
- 网格 cell 大小 = `可用宽度 / 列数`，**用百分比**控制：cell 高度 = 宽度（正方形）或按比例。
- 卡片内：预览图占 cell 顶部（约 60%），名称占底部（约 25%），大小占约 15%，比例协调。
- 图片/视频显示预览/封面，其余显示类型图标。

## 5. 导入 / 导出
- **导入**：文件/文件夹 → 复制进内部目录 → 插入 files 记录（parent_id=0 根目录）→ 返回。
  - 导入后在当前目录刷新可见（导入到根目录）。
- **导出**：把内部文件（internal_path）复制到用户选择的系统位置（getSaveLocation）。
  - 入口：文件更多菜单 + 多选栏「导出」。

## 6. 文件操作
- 预览（按类型打开查看器，读取 internal_path）。
- 重命名 / 删除 / 移动到文件夹 / 导出。
- 多选批量：加标签 / 移除标签 / 移动 / 导出 / 删除。

## 7. 标签页
- 列出所有用户标签（颜色圆点 + 计数）。
- 点标签 → 回到「文件」页并按该标签过滤（只显示带此标签的文件）。
- 新建 / 重命名 / 改色 / 删除标签。

## 8. 搜索
- 按名称搜索库内文件。搜索结果也走列表/网格视图。

## 9. 更多页
- 导入文件 / 导入文件夹 / 新建目录 / 库统计 / 关于说明。

## 10. 设置
- **网格视图列数**（1~6，默认按屏幕宽度自适应）。
- 其它偏好后续扩展。

## 11. 关键约束
- **标签 ≠ 类型**：列表/网格永不显示类型标签。
- **首页干净**：只显示目录内容，无分类栏/标签栏。
- **统一高度/比例**：列表固定行高，网格百分比布局，避免"大格子小内容"。
