# legacy /（保留方案，非导入式）

> **本目录为「保留方案 / 备用」，不作为主流程。**

这里存放**直接访问系统文件**的旧版功能：

- `file_manager/`  系统文件浏览器（直接读系统文件，非导入式）
- `search/`  系统文件搜索
- `settings/`  设置
- `about/`  关于

## 与主方案的关系

当前 APP 主流程是**导入式**（`../library/`）：
通过导入接口把系统文件复制进内部数据库，再查看/管理/打标签。

本目录保留的是旧版「直接管理系统文件」方案，作为**备用 / 参考实现**保留，
不参与主流程。如需启用，可把 `main.dart` 的 home 改回 `FileManagerPage`。
